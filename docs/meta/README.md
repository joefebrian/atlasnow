# Meta WhatsApp rate cards (IDR)

Official to-be cards Meta published for **1 October 2026**. AtlasNow estimates use these numbers now (do not wait until 1 Oct). Meta still invoices the July card until 00:00 in the WABA timezone on 1 Oct 2026.

| File | What |
|---|---|
| `whatsapp-list-rates-2026-10-01.csv` | List rate per market × category, including **service**. |
| `whatsapp-volume-tiers-2026-10-01.csv` | Utility / authentication / authentication-international volume tiers. |

Indonesia list rate is unchanged vs July 2026: marketing **586.33**, utility / authentication / service **356.65**, authentication-international **1940.13**. Service volume tiers for Indonesia start after **750,000** messages/month — list rate is what every current Atlas merchant will pay.
